What changed: airline service timeline

The numbered markers on the charts match this list, and you can click a number on any chart for details. The gray “no service” bands are computed from the data (three or more months with zero departing passengers); the list explains what was happening. Lincoln and Omaha have no changes marked because I found no clear, dated route changes for them, and events with vague or conflicting dates were left out. Allegiant has also flown Las Vegas–Grand Island since 2008, before this data begins, so it has no marker.
